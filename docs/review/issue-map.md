A bill's committees are those it was referred to (the committee code carried by the history row), heard in or voted in, in order of first appearance.
`LOCATION_CODE_TBL.long_description`. Each policy subject is one neutral issue named with the committees' own words;
Assembly and Senate committees on the same subject share an issue. Fiscal and procedural committees map to no issue.
An issue id and its number `n` are stored in user profiles and are never reused or renamed.
