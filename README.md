# ca-leg-data

Public, data-only pipeline for California Legislature records.

A scheduled job downloads the Legislative Counsel's official bulk files from
https://downloads.leginfo.legislature.ca.gov/, parses them, and publishes statewide JSON snapshots.

- **Data:** public domain. California Government Code §10248.5: the information the Legislative Counsel
  makes available under §10248 "is within the public domain and the State of California retains no
  copyright or other proprietary interest in that information."
- **Code:** MIT (see `LICENSE`).
- **What is not here:** no secrets, no application source, no user data of any kind.

Found a data error? Open an issue with the bill number and what looks wrong.

Status: under construction.
